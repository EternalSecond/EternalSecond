### `01` / BEHIND THE CODE

I'm **EternalSecond**, a developer who enjoys exploring how machines learn — from labeled examples, from patterns hidden in data, and from interacting with an environment.

I'm interested in the whole process: preparing data, building models, running experiments, understanding the results, and figuring out what to change next. I like getting hands-on with ideas and seeing how they behave outside a theoretical explanation.

**Supervised Learning, Unsupervised Learning, and Reinforcement Learning** are all part of what I enjoy working on. Each offers a different way to approach a problem, and exploring those differences is a big part of what keeps me curious.

Alongside machine learning, I build **Python backends** with **FastAPI** and **Django**. I enjoy the engineering side too: organizing application logic, designing APIs, and connecting individual components into a working system.

<br>

### `02` / WHAT KEEPS ME CURIOUS

#### 🎯 Supervised Learning · Learning from examples

I enjoy working with labeled data and exploring how models learn the relationship between inputs and targets. Classification, regression, and neural networks interest me — along with the decisions that shape their results.

I'm curious about how data quality, feature choices, model architecture, and training settings affect performance. Building a model is part of the fun; understanding its mistakes and improving how it generalizes is another.

#### 🔎 Unsupervised Learning · Discovering structure

I like the idea of giving a model data without predefined answers and exploring what structure emerges. Clustering, representation learning, and dimensionality reduction offer interesting ways to look at a dataset from a different perspective.

What interests me is discovering relationships that aren't immediately obvious: which examples belong together, which features capture useful information, and how complex data can be represented more meaningfully.

#### 🤖 Reinforcement Learning · Learning through interaction

Reinforcement Learning is especially exciting to me because it brings learning into a loop of **observation, action, and feedback**. An agent makes a decision, changes its environment, and learns from what happens next.

I enjoy experimenting with agents for games and simulations, thinking about reward design, and exploring how behavior changes during training. The balance between exploration and exploitation — and the challenge of getting useful behavior from a reward signal — makes this area particularly interesting.

#### ⚙️ Backend Development · Connecting the pieces

I also enjoy building the software around an idea: APIs, application logic, and services that make individual components work together.

With **Python, FastAPI, and Django**, I explore how to structure backend applications and make them easier to understand, extend, and maintain. I'm interested in the connection between machine learning experiments and the systems that can make them useful.
